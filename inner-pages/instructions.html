How To Customise Fexiva

A short guide to the variables, components, CMS collections and forms in this template, so you can make it yours without touching a line of code.

Getting Started

Fexiva is built entirely with native Webflow elements, variables and components. Apart from the small GSAP counter described below, there is no custom code, no third-party script and no external font to install, so the template works the moment you open it in the Designer.

  1. Open the Style Guide page first. It shows every heading, text size, colour, button and form field the template uses.
  2. Replace the logo: upload your SVG to the Assets panel and swap it on the Navbar and Footer components. Both use a single asset, so you only do it twice.
  3. Update the site name, SEO titles and Open Graph image in Page settings for each page.
  4. Set your form notification email under Site settings, Forms, before publishing.

Colours, Spacing & Typography

Every colour, font, size, line height, letter spacing, spacer and radius is a Webflow variable. Change the variable once and the whole site updates.

  • Color holds the primitives (Primary, Gray, White and Accent scales) and the semantic tokens that reference them: Text Color, Background Color, Border Color and Button Color.
  • Sizes holds the Spacer scale (5XSM to 5XL), container widths and radius tokens, with modes for Desktop LG, Desktop SM, Tablet and both mobile widths.
  • Typography holds the two font families, weights, the H1 to H6 and Paragraph 1 to 5 sizes, line heights and letter spacing, with the same responsive modes.
To rebrand quickly, change Primary Color 500 for the accent, Primary Color 900 for the page background and Primary Color 700 for cards. The semantic tokens pick the new values up automatically.

Components

Repeated sections live in the Components panel. Edit the main component to update every page, or use the exposed properties to change a single instance.

  • Navbar and Footer are placed on every page. Edit the links, logo and social icons inside the component once.
  • Primary Button, Secondary Button and Icon Button expose Text and Link properties. Add the combo class is-active to a Secondary Button for the solid state.
  • CTA exposes Heading, Body, Button Text and Button Link. FAQ Item exposes Question and Answer.
  • Pricing Plans and Partner Logos are shared between the Home page and the Pricing and Contact pages, so the tiers and logos stay consistent.

CMS Collections

Two collections power the dynamic pages. Each has a template page with dynamic SEO settings already bound.

  • Blog Posts: name, slug, excerpt, main image, category, author name and photo, publish date, read time, rich-text body and a featured switch used by the Blog page hero.
  • Integrations: name, slug, logo (SVG), short description, category and rich-text body with figures, lists and headings.
Add items from the CMS panel and they appear in the lists automatically. Headings inside rich text use the H4 tag style, so keep article sub-headings at H4 for a consistent look.

Forms

All forms are native Webflow forms, so submissions arrive in the Forms tab of your site settings with no integration required.

  • Contact form on the Contact page with name, email, service select and message fields. Success and error messages are styled with the contact-form-success and contact-form-error classes.
  • Newsletter form inside the Footer component.
  • Password form on the 401 page. Enable it under Site settings, General, Password protection.
Keep the submit buttons as native form buttons. Restyle them with the primary-button class rather than replacing them with a component instance, otherwise the form will not submit.

SVG Icons

Interface icons are inline SVG elements placed directly in the canvas, not embeds. They use the current text colour, so you recolour an icon by changing the Color property of the icon or its parent in the Style panel.

  1. Select the icon element in the Navigator (for example feature-card-icon-svg or contact-info-icon-svg).
  2. To swap the glyph, delete it and paste a new SVG that uses stroke or fill set to currentColor, then give it the same class so it keeps its size.
  3. Social icons in the Footer and Contact page are SVG image assets. Replace them from the Assets panel.

How To Edit GSAP Animations

Fexiva uses one small GSAP script: a number counter that counts each statistic up from zero the first time it scrolls into view. It relies on the GSAP and ScrollTrigger libraries that Webflow loads natively, so there is no external script to maintain. The code lives in Site settings → Custom code → Footer code, under the comment “Counter Animation”.

Element map

  • Home → Hero → hero-stats-number (2 elements, “120K”)
  • Home → About → about-stat-number (3 elements, “$5B”, “120”, “75”)
  • Each of these carries the custom attribute data-counter = true. The script reads the visible text, keeps any prefix (“$”) and suffix (“K”, “B”, “%”), and animates only the number in between. Thousands separators and one decimal place are preserved automatically.

Full script

<!-- Counter Animation -->
<script>
  window.Webflow ||= [];

  window.Webflow.push(() => {
    document.querySelectorAll("[data-counter]").forEach((counter) => {
      // Animate the first text node (the number), so a trailing <span>+</span> is left alone
      const textNode = [...counter.childNodes].find(
        (n) => n.nodeType === 3 && n.textContent.trim()
      );
      const textEl = textNode || counter.firstElementChild || counter;
      const original = textEl.textContent.trim();

      const match = original.match(/^([^0-9.-]*)([0-9.,-]+)(.*)$/);
      if (!match) return;

      const prefix = match[1];
      const number = match[2].replace(/,/g, "");
      const suffix = match[3];

      const target = parseFloat(number);
      if (Number.isNaN(target)) return;

      const hasDecimal = number.includes(".");
      const hasComma = original.includes(",");

      const value = { current: 0 };

      gsap.fromTo(
        value,
        { current: 0 },
        {
          current: target,
          duration: 1.8,
          ease: "power2.out",
          scrollTrigger: {
            trigger: counter,
            start: "top 88%",
            once: true
          },
          onUpdate: () => {
            let formattedValue = hasDecimal
              ? value.current.toFixed(1)
              : Math.floor(value.current);

            if (hasComma && !hasDecimal) {
              formattedValue = Number(formattedValue).toLocaleString();
            }

            textEl.textContent =
              prefix + formattedValue + suffix;
          }
        }
      );
    });
  });
</script>

Values you can change

  • duration: 1.8 — how many seconds the count takes. Keep it between 0.8 and 3.
  • ease: "power2.out" — the easing curve. Try "power1.out" for a gentler finish or "expo.out" for a snappier one.
  • start: "top 88%" — when the count begins. "top 88%" fires as the number reaches the lower part of the viewport; "top 100%" fires the moment it enters.
  • once: true — the count plays a single time. Set it to false to replay every time the number scrolls back into view.
  • toFixed(1) — decimals shown for values such as “4.9”. Change the 1 to 2 for two decimal places.

How to update the script

  1. Open Site settings → Custom code and scroll to the Footer code field.
  2. Find the block that starts with the comment “Counter Animation” and edit the values listed above. Leave everything else as it is.
  3. Click Save changes, then publish the site. Custom code only runs on the published site, never inside the Designer.
  4. To animate another number, select its text element in the Designer, open Element settings → Custom attributes and add data-counter with the value true. The visible text must contain a number, for example “98%” or “1,200+”.
  5. To stop one number animating, remove its data-counter attribute. Nothing else changes.

How to remove it safely

  1. Open Site settings → Custom code → Footer code.
  2. Delete the whole block from the comment “Counter Animation” down to its closing script tag. Do not touch anything above it.
  3. Save changes and publish. The statistics now render as static text with exactly the same layout, spacing and styling — nothing on the page depends on the script.
  4. Optional: remove the data-counter attributes from the five number elements so the site carries no unused attributes.
The script expects GSAP and ScrollTrigger to be loaded by Webflow. Check Site settings → GSAP: the core library and the ScrollTrigger plugin must both be enabled, otherwise the numbers simply stay static.

Utility Pages

The Style Guide, Licenses, Changelog, Instructions, 404 and 401 pages are ready to use. All of them carry a noindex meta tag in their page settings so search engines skip them.

  • The 404 page keeps the shared Navbar and Footer so visitors can always find their way back.
  • The 401 page uses the original Webflow password elements restyled with the template classes.
  • Update the Licenses page if you add assets from a new source, and log your own changes on the Changelog page.
