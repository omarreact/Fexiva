Version 1.0.0
September 21, 2026

Initial Release

The first public release of Fexiva, a finance and spend-management template for Webflow. Everything is built with variables, reusable components and native Webflow elements, with no custom code beyond one small GSAP counter.

  • Nine static pages: Home, Features, About, Pricing, Contact, Blog, Integrations, Style Guide and the utility pages.
  • Two CMS collections with template pages: Blog Posts and Integrations.
  • Global components for Navbar, Footer, CTA, FAQ, Pricing Plans, Partner Logos and all three button styles.
  • Colour, spacing, radius and typography variables with responsive modes for every breakpoint.
  • Native contact, newsletter and password forms with styled success, error and focus states.
